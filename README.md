# Generate ULIDs

Raycast extension to generate ULIDs.

## Installation
1. Install [Raycast](https://raycast.com/)
2. Install [Node.js](https://nodejs.org/)
3. Clone this repository
4. Run `npm install && npm run build` in the cloned directory
5. Open Raycast and go to Extensions
6. Click on the "+" button and select "Add Extension"
7. Select the cloned directory
8. Click "Add" to add the extension
9. You should now see the extension in Raycast
10. You can now use the extension by typing "ulid" in Raycast
