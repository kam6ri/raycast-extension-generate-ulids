# Generate ULIDs

Raycast extension to generate ULIDs.

## Installation
1. Install [Raycast](https://raycast.com/)
2. Install [Node.js](https://nodejs.org/)
3. Clone this repository
4. Run `npm install` in the cloned directory
5. Run `npm run build` to build the extension
6. Open Raycast and go to Extensions
7. Click on the "+" button to add a new extension
8. Select "Add from file" and choose the `dist` folder in the cloned directory
9. Select the `generate-ulid` folder and click "Open"
10. The extension should now be available in Raycast
11. You can now use the extension by typing "generate ulid" in Raycast
12. You can also use the extension by typing "ulid" in Raycast
